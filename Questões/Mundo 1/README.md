# Mundo 1 — Fundamentos

Os desafios estão agrupados pelo assunto que caiu em cada aula.
Clica no número pra abrir o arquivo. O enunciado também fica no topo de cada `.py`.

`[x]` já resolvido · `[ ]` ainda vou fazer

## Primeiros comandos

- [ ] **[001 — Olá, Mundo!](./desafio_01.py)**  
  Crie um programa que escreva "Olá, Mundo!" na tela.
- [x] **[002 — Respondendo ao usuário](./desafio_02.py)**  
  Faça um programa que leia o nome de uma pessoa e mostre uma mensagem de boas-vindas de acordo com o valor digitado.

## Tipos primitivos e saída de dados

- [x] **[003 — Somando dois números](./desafio_03.py)**  
  Crie um programa que leia dois números e mostre a soma entre eles.
- [x] **[004 — Dissecando uma variável](./desafio_04.py)**  
  Faça um programa que leia algo pelo teclado e mostre na tela o seu tipo primitivo e todas as informações possíveis sobre ele.

## Operadores aritméticos

- [x] **[005 — Antecessor e sucessor](./desafio_05.py)**  
  Faça um programa que leia um número inteiro e mostre na tela o seu sucessor e o seu antecessor.
- [x] **[006 — Dobro, triplo e raiz quadrada](./desafio_06.py)**  
  Crie um algoritmo que leia um número e mostre o seu dobro, o seu triplo e a sua raiz quadrada.
- [x] **[007 — Média aritmética](./desafio_07.py)**  
  Desenvolva um programa que leia as duas notas de um aluno, calcule e mostre a sua média.
- [x] **[008 — Conversor de medidas](./desafio_08.py)**  
  Escreva um programa que leia um valor em metros e o exiba convertido em centímetros e milímetros.
- [x] **[009 — Tabuada](./desafio_09.py)**  
  Faça um programa que leia um número inteiro qualquer e mostre na tela a sua tabuada.
- [x] **[010 — Conversor de moedas](./desafio_10.py)**  
  Crie um programa que leia quanto dinheiro uma pessoa tem na carteira e mostre quantos dólares ela pode comprar.
- [x] **[011 — Pintando parede](./desafio_11.py)**  
  Faça um programa que leia a largura e a altura de uma parede em metros, calcule a sua área e a quantidade de tinta necessária para pintá-la, sabendo que cada litro de tinta pinta uma área de 2m².
- [x] **[012 — Calculando descontos](./desafio_12.py)**  
  Faça um algoritmo que leia o preço de um produto e mostre o seu novo preço, com 5% de desconto.
- [x] **[013 — Reajuste salarial](./desafio_13.py)**  
  Faça um algoritmo que leia o salário de um funcionário e mostre o seu novo salário, com 15% de aumento.
- [ ] **[014 — Conversor de temperaturas](./desafio_14.py)**  
  Escreva um programa que converta uma temperatura digitada em °C para °F.
- [ ] **[015 — Aluguel de carros](./desafio_15.py)**  
  Escreva um programa que pergunte a quantidade de Km percorridos por um carro alugado e a quantidade de dias pelos quais ele foi alugado. Calcule o preço a pagar, sabendo que o carro custa R$60 por dia e R$0,15 por Km rodado.

## Utilizando módulos (math, random)

- [x] **[016 — Quebrando um número](./desafio_16.py)**  
  Crie um programa que leia um número real qualquer pelo teclado e mostre na tela a sua porção inteira.
- [x] **[017 — Catetos e hipotenusa](./desafio_17.py)**  
  Faça um programa que leia o comprimento do cateto oposto e do cateto adjacente de um triângulo retângulo, calcule e mostre o comprimento da hipotenusa.
- [x] **[018 — Seno, cosseno e tangente](./desafio_18.py)**  
  Faça um programa que leia um ângulo qualquer e mostre na tela o valor do seno, cosseno e tangente desse ângulo.
- [x] **[019 — Sorteando um item na lista](./desafio_19.py)**  
  Um professor quer sortear um dos seus quatro alunos para apagar o quadro. Faça um programa que ajude ele, lendo o nome deles e escrevendo o nome do escolhido.
- [x] **[020 — Sorteando uma ordem na lista](./desafio_20.py)**  
  O mesmo professor do desafio anterior quer sortear a ordem de apresentação de trabalhos dos alunos. Faça um programa que leia o nome dos quatro alunos e mostre a ordem sorteada.
- [x] **[021 — Tocando um MP3](./desafio_21.py)**  
  Faça um programa que abra e reproduza o áudio de um arquivo MP3.

## Manipulando texto

- [x] **[022 — Analisador de textos](./desafio_22.py)**  
  Crie um programa que leia o nome completo de uma pessoa e mostre: o nome com todas as letras maiúsculas, com todas minúsculas, quantas letras ao todo (sem espaço) e quantas letras tem o primeiro nome.
- [x] **[023 — Separando dígitos de um número](./desafio_23.py)**  
  Faça um programa que leia um número de 0 a 9999 e mostre na tela cada um dos dígitos separados (unidade, dezena, centena e milhar).
- [x] **[024 — Verificando as primeiras letras de um texto](./desafio_24.py)**  
  Crie um programa que leia o nome de uma cidade e diga se ela começa ou não com o nome "Santo".
- [x] **[025 — Procurando uma string dentro de outra](./desafio_25.py)**  
  Crie um programa que leia o nome completo de uma pessoa e mostre se ela tem "Silva" no nome.
- [x] **[026 — Primeira e última ocorrência de uma string](./desafio_26.py)**  
  Faça um programa que leia uma frase qualquer e mostre: quantas vezes aparece a letra "A", em que posição ela aparece a primeira vez e em que posição ela aparece a última vez.
- [x] **[027 — Primeiro e último nome de uma pessoa](./desafio_27.py)**  
  Faça um programa que leia o nome completo de uma pessoa, mostrando em seguida o primeiro e o último nome separadamente.

## Condições (if / else)

- [x] **[028 — Jogo da Adivinhação v1.0](./desafio_28.py)**  
  Escreva um programa que faça o computador "pensar" em um número inteiro entre 0 e 5 e peça para o usuário tentar descobrir qual foi o número escolhido. O programa deverá escrever na tela se o usuário venceu ou perdeu.
- [x] **[029 — Radar eletrônico](./desafio_29.py)**  
  Escreva um programa que leia a velocidade de um carro. Se ele ultrapassar 80km/h, mostre uma mensagem dizendo que ele foi multado. A multa custa R$7,00 por cada Km acima do limite.
- [x] **[030 — Par ou ímpar?](./desafio_30.py)**  
  Crie um programa que leia um número inteiro e mostre na tela se ele é PAR ou ÍMPAR.
- [x] **[031 — Custo da viagem](./desafio_31.py)**  
  Desenvolva um programa que pergunte a distância de uma viagem em Km. Calcule o preço da passagem, cobrando R$0,50 por Km para viagens de até 200km e R$0,45 para viagens mais longas.
- [x] **[032 — Ano bissexto](./desafio_32.py)**  
  Faça um programa que leia um ano qualquer e mostre se ele é BISSEXTO.
- [x] **[033 — Maior e menor valores](./desafio_33.py)**  
  Faça um programa que leia três números e mostre qual é o maior e qual é o menor.
- [x] **[034 — Aumentos múltiplos](./desafio_34.py)**  
  Escreva um programa que pergunte o salário de um funcionário e calcule o valor do seu aumento. Para salários superiores a R$1.250,00, calcule um aumento de 10%. Para os inferiores ou iguais, o aumento é de 15%.
- [x] **[035 — Analisando triângulo v1.0](./desafio_35.py)**  
  Desenvolva um programa que leia o comprimento de três retas e diga ao usuário se elas podem ou não formar um triângulo.
